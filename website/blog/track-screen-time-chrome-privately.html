Track Screen Time on Chrome (Free & Private)

By Adnan · Updated October 24, 2026 · 7 min read

The short answer: Chrome on a computer has no built-in screen time, so to track it you install an extension that counts the time you spend on each website. The catch is that such an extension can see which sites you visit. WebWell is a free, open-source option that does it on your device only: no account, no server.

How to track screen time on Chrome in 3 steps

  1. Install a tracker. Open WebWell in the Chrome Web Store and click Add to Chrome. It works the same way in Brave. A short welcome tour shows you around.
  2. Browse as normal. It counts time on the website you are actually looking at, and pauses when you are idle or when the window is in the background.
  3. Open your dashboard. Click the chart icon at the top right of your new tab, or the WebWell icon in the toolbar. You will see today's time, each website, and a daily score.

So an extension is the way. The real choice is which one, because the data it collects is your browsing history.

How website time trackers work

A tracker watches which tab is active and for how long, then adds the time to that site. The good ones get three details right:

  • Only the active tab counts. Twenty open tabs shouldn't mean twenty hours.
  • Idle time is ignored. If you walk away, the clock should stop.
  • An unfocused window doesn't count. A video playing in a window behind your work isn't "time on YouTube".

The big difference between trackers is not counting, it's where the data goes. Some send your history to their servers so they can show it on a website or across devices. Others keep it on your computer.

Five things to check before you install one

  1. Does it need an account? An account usually means your data lives on someone's server.
  2. What does the privacy policy say, exactly? Look for specifics: what is stored, where, and when anything is sent. "We take privacy seriously" says nothing.
  3. What does it record? The domain (github.com) is enough to count time. Full URLs and page titles reveal much more.
  4. Which permissions does it ask for, and when? Time tracking needs to know the active tab. It doesn't need to read the content of every page. We compared them in a data study of new tab and focus extensions.
  5. Can you check it? Open-source extensions let anyone read the code. You don't have to read it yourself; it's enough that others can.

Turning numbers into a better day

Data on its own changes nothing. A few habits that help:

  • Mark each site as productive, neutral or distracting, so you see the balance rather than a long list.
  • Look at your rhythm. Most people have a slump at the same hour every day. Plan focused work before it.
  • Set a gentle limit on one or two sites, not ten. A single notification is easier to respect than a wall of blocks.

Questions

Does Chrome have built-in screen time?

Not on desktop. Chrome does not show how long you spend on each website. Phones have built-in screen time, but on a computer you need an extension to count time per site. Operating-system tools mostly report the time you spend in Chrome as one app, not in each website.

How do I track screen time on Chrome for free?

Install a free time-tracking extension such as WebWell, browse as normal, and open its dashboard. It counts time per website automatically while you work. WebWell is free, open source and needs no account.

Can I see how long I spend on each website in Chrome?

Yes, with an extension. WebWell shows time per website for today and for the week, a daily productivity score, your streaks and a 24-hour chart of when you browse most.

Is it private? Does my browsing history leave my computer?

With WebWell it does not. It records only the website name (for example notion.so) and the seconds spent, never full addresses, page titles or page content, and it keeps them in your browser. There is no account and no server. You can export or delete the data from Settings.

Does it track Incognito windows?

By default, no. Chrome does not run extensions in Incognito unless you allow it for that extension in its settings.

Does it work on my phone or in other browsers?

WebWell works in desktop Chrome and Brave. It does not track a phone. Phones already include built-in screen time in their settings.
