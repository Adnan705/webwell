Track screen time on Chrome privately

By Adnan · Updated October 24, 2026 · 3 min read

Short answer: Chrome on a computer has no built-in screen time, so you track it with an extension that counts the time you spend on each website. WebWell is a free, open-source one that keeps everything on your device: no account, no server.

How to track screen time on Chrome

  1. Install a tracker. Open WebWell in the Chrome Web Store and click Add to Chrome. It works the same in Brave.
  2. Browse as normal. It counts the website you are actually looking at, and pauses when you are idle or the window is in the background.
  3. Open the dashboard. Click the chart icon on your new tab, or the WebWell icon in the toolbar, to see today's time per website.

What to check before you install one

  • No account needed. An account usually means your history sits on someone's server.
  • Records domains, not pages. github.com is enough to count time. Full URLs and page titles reveal much more.
  • Honest permissions. Counting time needs the active tab, not the content of every page. See how new tab and focus extensions compare.
  • Only the active tab counts, and idle time is ignored. Otherwise twenty open tabs become twenty hours.
  • Open source and a clear privacy policy, so anyone can check what it does.

What WebWell tracks, and what it keeps

It shows time per website for today and the week, a daily productivity score, streaks and a 24-hour chart of when you browse most. It stores only the site name and the seconds, in your browser's local storage. Uninstalling deletes it, and you can export a copy from Settings first. See the privacy policy for every permission and why. To act on the numbers, try a focus timer or block YouTube Shorts.

Questions

Does Chrome have built-in screen time?

Not on desktop. Chrome does not show how long you spend on each website, so you need an extension. Operating-system tools mostly report the time you spend in Chrome as one app, not per website.

How do I track screen time on Chrome for free?

Install a free time-tracking extension such as WebWell, browse as normal, and open its dashboard. It counts time per website automatically. WebWell is free, open source and needs no account.

Is my browsing history kept private?

With WebWell, yes. It records only the website name (for example notion.so) and the seconds spent, never full addresses, page titles or page content, and keeps them in your browser. There is no account and no server.

Does it track Incognito windows?

By default, no. Chrome does not run extensions in Incognito unless you allow it for that extension in its settings.

Does it work on my phone or in other browsers?

WebWell works in desktop Chrome and Brave. It does not track a phone, which already has built-in screen time in its settings.
